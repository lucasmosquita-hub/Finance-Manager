# 💰 Finance Manager

Sistema de gerenciamento financeiro pessoal desenvolvido em Python utilizando Flask.

## 📌 Sobre o projeto

O Finance Manager é uma aplicação web desenvolvida com o objetivo de facilitar o controle financeiro pessoal.

O sistema permite cadastrar receitas e despesas, calcular automaticamente o saldo disponível e visualizar o histórico de movimentações.

O projeto está sendo desenvolvido gradualmente, aplicando conceitos de desenvolvimento Backend, Frontend e Banco de Dados.

## 🚀 Funcionalidades implementadas

- [x] Dashboard financeiro.
- [x] Cadastro de receitas.
- [x] Cadastro de despesas.
- [x] Cálculo automático de receitas.
- [x] Cálculo automático de despesas.
- [x] Cálculo do saldo disponível.
- [x] Histórico de movimentações.
- [ ] Integração com SQLite.
- [ ] Persistência permanente de dados.
- [ ] Edição de movimentações.
- [ ] Exclusão de movimentações.
- [ ] Relatórios financeiros.

## ⚙️ Como executar

1. Clone o repositório.
2. Entre na pasta do projeto.
3. Crie um ambiente virtual:

```bash
py -m venv venv
```

4. Ative o ambiente virtual no Windows:

```powershell
.\venv\Scripts\Activate.ps1
```

5. Instale o Flask:

```bash
pip install flask
```

6. Execute a aplicação:

```bash
py app.py
```

7. Acesse no navegador:

```text
http://127.0.0.1:5000
```
