# Histórico de Desenvolvimento — Finance Manager

## 08/11/2026 — Primeira versão funcional

### 1. Configuração do ambiente
- Configuração do ambiente virtual Python (venv).
- Instalação e configuração do Flask.
- Inicialização do servidor local.
- Configuração do ambiente de desenvolvimento no VS Code.

### 2. Desenvolvimento do Backend
- Criação da aplicação Flask.
- Implementação da rota principal `/`.
- Configuração dos métodos HTTP GET e POST.
- Recebimento de informações através de formulários HTML.
- Processamento dos dados utilizando Python.

### 3. Desenvolvimento do Frontend
- Criação da estrutura HTML.
- Implementação da identidade visual com CSS.
- Desenvolvimento do Dashboard financeiro.
- Criação dos cartões de indicadores financeiros.
- Desenvolvimento do formulário de receitas e despesas.
- Implementação do histórico de movimentações.

### 4. Funcionalidades implementadas
- Cadastro de receitas.
- Cadastro de despesas.
- Cálculo automático de receitas.
- Cálculo automático de despesas.
- Cálculo do saldo disponível.
- Contagem de movimentações.
- Exibição do histórico de lançamentos.

### 5. Tecnologias utilizadas
- Python
- Flask
- HTML5
- CSS3
- Jinja2
- Visual Studio Code

### 6. Próximos objetivos
- Implementação do banco de dados SQLite.
- Persistência permanente das movimentações.
- Edição de lançamentos.
- Exclusão de lançamentos.
- Melhorias na interface.
